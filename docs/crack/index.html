Demo phát hiện vết nứt

Model YOLOv8-seg fine-tune trên dataset DeepCrack, khoanh vùng vết nứt trên ảnh bạn chọn. Toàn bộ quá trình chạy ngay trên trình duyệt của bạn (ONNX Runtime Web, WebAssembly) — ảnh không được tải lên server nào, không cần GPU.

Model được train trên ảnh bê tông/tường hiện đại, chưa fine-tune riêng cho đá/gỗ/gạch di tích — đây là bản demo khái niệm (proof of concept), độ chính xác trên ảnh di sản thật có thể chưa cao.
